# Security Policy

## Scope

HARP is an active-development security architecture and MVP. Security reports are welcome, especially reports affecting the dashboard, event-processing boundaries, dependency hygiene, or future Hedera integrations.

## Reporting

Please do not publish sensitive vulnerability details in a public issue.

Until a dedicated security contact is configured, use a private GitHub security advisory for eligible vulnerabilities.

## Responsible Disclosure

Include:
- affected component and version/commit;
- reproduction steps;
- expected vs. actual behavior;
- security impact;
- suggested mitigation, when available.

Do not include credentials, private keys, customer telemetry or other sensitive data in reports.

## Production Disclaimer

HARP has not been represented as independently audited. Production and safety-critical deployments require independent security assessment, threat modeling, secure key management, monitoring, incident response and operational controls.
